# 观澜 (Guanlan)

fnOS（飞牛OS）系统监控应用：像任务管理器一样实时总览 NAS 各项资源，并以多时间尺度
（10 分钟 ~ 1 年）折线图记录与回看历史，带阈值告警与磁盘健康监视。

**仅 fnOS 管理员可用**（普通用户打开会被拒绝）。

## 功能

- **概览**：12 张资源卡片（CPU/内存/Swap/NPU/GPU/温度/风扇/网络含 IPv4/IPv6 内外网地址/磁盘 I/O/负载/进程/运行时长），压力色自适应（绿→黄→红）；实时曲线窗口 10 秒~24 小时可选；卡片与面板可拖拽排序（iOS 式让位动画）、面板高度/宽度可拖拽调整
- **温度 / 网络 / 磁盘**：独立页，多窗口曲线；磁盘健康信号（温度、I/O 错误计数、链路状态）与文件系统容量
- **历史**：10 分钟 / 1 小时 / 1 天 / 1 周 / 1 月 / 1 年，五组指标；**滚轮缩放自动下钻**到更细粒度数据层
- **进程**：只读列表，搜索 / 排序（CPU% 为单核基准）
- **异常警告**：阈值规则（指标 / 条件 / 持续时间 / 级别）可编辑；活跃告警 + 历史 + 确认；有未确认告警时 tab 标红
- **设置**：采集间隔（1~15s）与落盘粒度（5~60s）运行时可调即时生效；三层保留策略可配；存储体积估算
- 界面中文 / English 切换

## 技术栈与架构

- 后端：Go 单二进制（CGO_ENABLED=0，双架构 arm64/amd64），纯 Go SQLite（modernc.org/sqlite）
- 采集：`/proc` 与 `/sys`（CPU 每核、内存、8 路温度、风扇、GPU/NPU devfreq 频率、网卡速率、磁盘 I/O、负载、挂载容量），无特权运行，常驻内存 ~20MB、CPU <1%
- 存储：分层时序（L0 原始粒度默认 15s × 30 天 → L1 5 分钟 × 180 天 → L2 1 小时 × 365 天），滚动保留与增量降采样
- 前端：Vue 3 + Vite + vue-i18n + ECharts（按需引入），构建产物 go:embed 嵌入二进制
- 安全：生产模式仅信任 fnOS 网关注入的管理员身份；`/healthz` 免认证；POST 防跨站；SQLite 参数化；不监听 TCP 端口

## 安装

fnOS 应用中心安装 `guanlan.fpk`（或本仓库 Release 下载），安装即用，无需配置。
桌面打开「观澜」图标。

## 开发

```bash
./build.sh                      # 前端 → 嵌入 → 双架构 → fpk（pkg/guanlan/guanlan.fpk）
./guanlan -dev -data ./data     # 本机直跑开发实例，浏览器 http://IP:9780
```

构建要求：Go ≥ 1.23、Node ≥ 18、npm、fnpack。Go 模块走 goproxy.cn。

```
server/   Go 后端（collect 采集 / store 存储 / api 接口 / alert 告警）
web/      Vue 前端
pkg/      fpk 打包（manifest / cmd 生命周期脚本 / 图标 / config）
tools/    图标生成器
```

## 已知限制

- NPU/GPU **利用率百分比**位于 debugfs，fnOS 第三方应用无特权身份不可读；
  以「实时频率 ÷ 最高频率」百分比 + 专属温度曲线作为活动强度代理
- SMART 完整属性需 root；以盘温、`ioerr_cnt`、链路状态、容量作为健康信号
- 桌面端经统一网关（Unix socket）访问，无独立 TCP 端口（fnConnect 公网中继不可达第三方端口，属平台限制）
